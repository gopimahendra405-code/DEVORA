# 5-minute demo script

1. Open Dashboard.
2. Upload any text-based PDF or `.txt` notes.
3. Wait for "Study set created".
4. Show the AI Summary and concept chips.
5. Open Learn and reveal a flashcard.
6. Click "I know it +5 XP".
7. Answer a quiz question.
8. Open Progress and show XP, cards reviewed and quiz count.
9. Explain that the same responsive UI works as the mobile companion/PWA.
10. Mention that an LLM endpoint can be enabled with `.env`; the demo mode keeps the application functional without an API key.
